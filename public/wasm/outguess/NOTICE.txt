OutGuess 0.4 - WASM candidate - attribution and license notice
=============================================================

This directory contains a WebAssembly build of OutGuess 0.4, compiled from

  resurrecting-open-source-projects/outguess
  commit 24810e14327c2bbeedeaadd3e24491f2a4425c02

The upstream sources are unmodified.  Only two generated build headers
(src/config.h and src/jpeg-6b-steg/jconfig.h) were added outside the
upstream tree; see ../wasm-build/build_wasm.py.

----------------------------------------------------------------------------
Honesty note
----------------------------------------------------------------------------

This is a technical candidate, not a released product, and it is NOT wired
into the application.  "OutGuess 0.4" is a specific historical version of an
archived upstream project; this build does not claim compatibility with
OutGuess 0.2 / 0.13, with steghide, or with any other steganography tool.
The embedded payload carries no MAC: producing N bytes back does NOT prove
the passphrase was correct.
